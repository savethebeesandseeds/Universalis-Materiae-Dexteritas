What each experiment established

01

Change the body

Interactive construction

How does adding a block or changing a beam alter motion?

An anchored two-link assembly has one powered hinge and a passive elbow. Beam lengths, weights and mounted sensors change the simulated mechanism.

Boundary: this is a planar mechanism with no contact collisions. Arbitrary assemblies, walking and hardware transfer remain open.

Building bench ↗
02

Learn a control policy

RL baseline established

Can locally measured light and motion shape the motor’s choices?

The baseline learns three linear action-value functions using Expected SARSA and 56 hand-designed features. Its live page shows one run; that run alone is not a general learning result.

Mathematical object: a learned value matrix W with 168 coefficients. It is a policy’s value approximation, not a dynamics or transfer matrix.

Live light experiment ↗
03

Continue learning after change

Measured · 6 matched pairs

Does updating W after the source moves improve control?

Continued learning earned more integrated sensor reward than freezing the weights in all six matched comparisons, across two known bodies.

Boundary: the same six first-visit experiences and one declared source change. This establishes a contribution from updating the values within that experiment.

Adaptation evidence ↗
04

Test an earlier value function

Measured · 6 return cases

When the source returns, is an older W still useful?

Restoring first-visit values improved the declared early-return reward comparison in all six cases relative to freezing the latest values.

Boundary: the experiment selected the checkpoint. The droid did not autonomously recognize the return or decide which values to restore.

Retention evidence ↗
05

Distinguish sensory conditions

Measured · withheld probes

Do local sensor histories distinguish the two light conditions?

A separate history classifier achieved 93.75% and 95.45% accuracy on the two bodies. Current readings reached 73.86% and 72.16%. Removing light gave 50%.

Boundary: supervised A/B labels, matched motor probes and stationary sources. High classification accuracy is neither a physical-state observer nor calibrated confidence.

Context evidence ↗
06

Identify a transition model

Measured · 72 trials and replays

Can z and a known future request predict unseen sensor responses?

Both the 12-state current-output model and 142-state history model passed the declared prediction gate on all three bodies. History reduced one-second composite error by 47%, 55% and 64% versus persistence.

Boundary: history helped at shorter horizons, but its necessity is not established. Light prediction improved less than the composite score; these models have not yet selected actions in closed-loop control.

States, values and model equations+

The common language

These objects are different.

x

Physical state

Joint positions and velocities, motor and sensor internals. The simulator advances this state.

z

Predictive state

Local measurement and request history arranged into coordinates for an identified model.

A, B, C, D

Dynamics surrogate

Maps for predicting how those coordinates and measured outputs respond to a request.

Q, π

Value and control

Expected action value and the policy that chooses a command. Better prediction must still earn better control.

Proposed questions · not yet tested

A learning engine across constructions

The larger goal is reusable learning that needs little new experience after a child assembles or changes a body. The predictor adds a diagnostic tool; it does not choose our next control architecture. These questions will need their own declared experiments.

Learn with little new experience
Can prior learning help a newly assembled body act through its senses, and how much fresh experience does it need?

Transfer across supported topologies
Once the simulator supports them, could training on a T-Rex help a snake construction withheld from training? This is a proposed transfer test, not a demonstrated capability.

Contact, standing and recovery
What changes when the creature must support its weight, keep balance, fall and recover? These require new physical capabilities and tests.

Completed experiments retain protocols, native reports, source fingerprints and exact replay checks. Replays verify reproducibility; they are not additional independent trials.
